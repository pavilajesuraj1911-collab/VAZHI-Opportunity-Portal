VAZHI homepage layout update

1. Replace your existing app.py with this app.py.
2. Keep your existing pages/ folder and utils.py (if your other pages use it).
3. Keep your creator image at assets/pavi.jpeg. The homepage will show a placeholder if it is missing.
4. In the VS Code terminal, activate your existing virtual environment if needed, then run:
   python -m streamlit run app.py

This file updates the homepage layout and visual styling only; it does not replace your separate pages.
